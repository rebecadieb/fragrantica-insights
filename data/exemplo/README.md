# Dados de exemplo (FICTÍCIOS)

Perfumes, marcas e reviews desta pasta foram **inventados** para demonstrar e testar o
pipeline sem depender da coleta no site. Não representam produtos nem opiniões reais.

Os arquivos seguem exatamente o formato gerado pelo notebook de coleta do Colab
(`perfumes.csv`, `detalhes_perfumes.csv`, `reviews.csv`), então servem também como
referência de layout para os seus dados reais em `data/input/`.
